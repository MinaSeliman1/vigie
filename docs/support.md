# Support Vigie

## Signaler un problème

Le support se fait par le canal indiqué par l’organisation cliente. Pour permettre un diagnostic rapide, indiquez :

- le centre et le compte concerné, sans envoyer de mot de passe;
- la page et l’action qui posent problème;
- l’heure approximative et le navigateur utilisés;
- l’identifiant `X-Request-Id` affiché dans la réponse ou dans les journaux, si disponible;
- une description reproductible et le résultat attendu.

Ne joignez pas de certification, de liste d’employés ou d’autre donnée personnelle si elle n’est pas nécessaire. Un utilisateur réel peut supprimer son compte depuis **Compte → Supprimer mon compte**; le mot de passe actuel et la confirmation `SUPPRIMER` sont exigés. Le responsable de l’organisation peut demander la correction ou la suppression d’un compte après vérification de son autorité; la suppression conserve les éléments d’audit exigés par la politique interne.

## Niveaux de priorité

**Urgent** : impossibilité générale de se connecter ou risque d’accès non autorisé. **Élevé** : un quart publié ou une certification est incorrectement bloqué. **Normal** : anomalie limitée à un écran ou demande d’amélioration. Les offres gratuites de démonstration n’incluent pas de garantie de temps de résolution.

Avant de partager le lien, vérifiez `/health`, `/health/ready`, la bannière **API connectée** et le dernier déploiement GitHub Actions. Les limites de veille de Render Free et de pause de Supabase Free peuvent retarder la première requête après une période d’inactivité.
