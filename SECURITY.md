# Signaler un problème de sécurité

Vigie est un projet en développement. N’utilisez pas les Issues publiques pour signaler une vulnérabilité, un secret exposé ou une donnée personnelle.

Utilisez la fonction **Private vulnerability reporting** de GitHub dans l’onglet **Security** du dépôt [MinaSeliman1/vigie](https://github.com/MinaSeliman1/vigie/security), lorsque celle-ci est disponible. Décrivez la version ou le commit, les étapes de reproduction, l’impact observé et un moyen de vous joindre. N’envoyez jamais de mot de passe, de jeton JWT, de chaîne PostgreSQL ou de clé Resend.

L’équipe accuse réception, évalue le risque, corrige ou atténue le problème, puis coordonne la divulgation avec les personnes touchées. La procédure détaillée de continuité se trouve dans [Réponse aux incidents](docs/operations/incident-response.md).
